# 🏆 Founder Quest

A self-paced, hands-on game for learning **Claude Code & Cowork** by building a real business end-to-end — skills, memory, agents, MCP connectors, artifacts/dashboards, a designed website, and automation.

## ▶️ Play it

**▶️ Live site: https://scottg-dashboards-gorilla.github.io/henry-founder-quest/**

1. Open the site and **take the assessment** (`assessment.html`).
2. Copy the **Mission Briefing** it generates.
3. Paste it as your first message to Claude — Claude becomes your **Guide**.
4. Open the **Guidebook** (`guidebook.html`) and work the levels. Claude coaches; **you** build.
5. Earn XP, level up your company, beat the final boss, demo your live business.

## Files
| File | What it is |
|------|-----------|
| `index.html` | Landing page — start here |
| `assessment.html` | The onboarding quiz that generates the Mission Briefing |
| `guidebook.html` | The game: 10 levels + a final boss (full Cowork capability coverage) |
| `certificate.html` | Printable Certificate of Completion, earned by beating the boss |
